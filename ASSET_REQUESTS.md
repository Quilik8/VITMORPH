# Solicitudes de assets

**Todavía no se solicitan assets finales.** El recorrido y sus encuentros utilizan figuras y suelo vectoriales técnicos, identificados como provisionales.

La Biblia Visual contiene tres referencias piloto para Control, Ataque y Defensa. Se consultaron como dirección y no se copiaron aquí ni son assets integrados. No se generaron imágenes, sprites ni iconos. Las capturas de tests/evidence son evidencia del runtime, no arte del juego.

El jugador confirmó que las etiquetas de habilidades se sustituirán más adelante por imágenes diseñadas y efectos. La integración deberá preservar identificación accesible, foco, selección, Priorizar/Retener y reutilización, con estados legibles sin depender solo del color. Las dimensiones, archivos y variantes se concretarán cuando se prepare ese bloque; no crear iconos ficticios ni imponer el catálogo técnico como catálogo final.

Cuando un bloque futuro necesite arte, la solicitud indicará: imagen requerida, sistema o escena, dimensiones, formato, transparencia, orientación, poses, variantes, capas y límites técnicos relevantes. Los placeholders técnicos, si se usan, se identificarán como temporales.
