# Interfaz

Contiene la pantalla de combate, el Theme común y el campo de figuras técnicas. HUD compacto sin tarjetas; detalle de habilidad seleccionada y dos comandos compartidos. Cola y registro en Detalles/F3. Ratón, Tab, 1–4/P/R; sin pausa ni ataques manuales. La arena muestra preparación, objetivo, ejecución e impacto.

La iteración 03 proyecta un mismo mundo con seguimiento de cámara durante recorrido y encuentros. La iteración 04 comienza en exploración manual, con Reiniciar disponible fuera del combate. El HUD compacto y las barras aparecen solo durante combate. Su visibilidad no cambia las dimensiones del campo; no se añade otra pantalla.

La franja superior atb_strip.gd muestra carga independiente, actor actual y orden de listos; solo aparece en combate. El arco sobre actores sigue siendo preparación visual.
